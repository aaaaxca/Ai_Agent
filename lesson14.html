Claude Code 입문 — 내 컴퓨터 폴더 다루기

지난 시간에 폴더를 통째로 맡겼습니다. 결과는 좋았죠. 그런데 다음 주에 같은 엑셀이 또 옵니다. 다시 맡기면 결과가 지난주와 똑같이 나올까요? 숫자가 미묘하게 다르면요? 오늘은 같은 폴더를 다루지만 방식이 다른 도구, Claude Code를 처음 엽니다. 결과물만이 아니라 그 일을 하는 프로그램까지 남기는 도구입니다.

📍 오늘 배우는 것 — 폴더 맡기기와 Claude Code의 차이, Code 탭 열고 내 컴퓨터(Local) 폴더 연결, 허락 방식(권한 모드) 고르기, 폴더 규칙 파일 CLAUDE.md, 첫 계산 도구 만들어 다시 실행하기
1

둘 다 폴더를 다루는데, 뭐가 다른가

13차시의 폴더 맡기기(Cowork)도, 오늘의 Claude Code도 내 컴퓨터 폴더를 읽고 파일을 만듭니다. 겉보기엔 같아요. 차이는 무엇이 남느냐입니다.

🧭 한 줄로 기억하기

앱은 일을 해 주고, Claude Code는 그 일을 하는 '기계'를 만들어 준다.

남는 것결과물 (문서·표·정리된 폴더)결과물 + 다시 돌릴 수 있는 프로그램
다음 주에 같은 일을 하면AI가 다시 판단 → 조금씩 다를 수 있음같은 프로그램 실행 → 같은 방식으로 계산 (같은 파일이면 늘 같은 결과)
폴더에 두는 규칙안내 파일 (매번 "읽어라"고 말함)CLAUDE.md — 폴더를 열면 자동으로 읽힘
진행 방식맡기고 기다림계획을 보고 허락하며 한 단계씩

💡 판별 질문 하나: "결과가 매번 완전히 똑같아야 하는가?" — 그렇다(합계·비중·형식 변환) → Claude Code로 도구화. 판단이 좀 섞여도 된다(요약·분류·초안) → 앱에 맡기기.

⚠️ "정확해야 한다"와 "매번 똑같아야 한다"는 다릅니다. 주간보고의 숫자도 정확해야 하지만, 그 안엔 "이 메모의 '약 300'을 어떻게 처리할까" 같은 판단이 섞여 있죠. 판단이 하나도 없는 순수 계산만 도구로 갑니다.

코딩을 몰라도 되나요?

됩니다. 코드는 Claude Code가 씁니다. 여러분이 할 일은 지금까지와 같아요 — 무엇을, 어떤 순서로 하는지 말로 설명하고, 계획을 읽고, 결과를 검수하는 것. 이름에 'Code'가 붙었지만 오늘 우리가 쓰는 건 코딩 실력이 아니라 지시하는 실력입니다.

Code 탭 열기 — 폴더 연결과 첫 대화

  1. Claude 데스크톱 앱을 열고 사이드바 맨 위쪽의 Code를 누릅니다. (13차시에 설치한 그 앱 — Claude Code가 앱 안에 들어 있어서 따로 설치할 것은 없습니다)
  2. 입력창 아래 첫 번째 칸(실행 환경)에서 Local을 고릅니다. Cloud를 고르면 작업이 Anthropic 서버에서 돌아서 내 컴퓨터 폴더가 안 보입니다.
  3. 그 옆 칸에서 Open folder…(폴더 열기)를 눌러 작업 폴더를 고릅니다. Claude Code는 기본적으로 이 폴더 안에서 일합니다.
  4. 입력창 아래의 권한 모드를 수동으로 맞춥니다. 처음엔 자동에 체크돼 있을 수 있으니 꼭 바꾸세요. (아래 표 참고 — 오늘은 무엇을 하는지 하나하나 보는 게 목표)
  5. 입력창에 평소처럼 한국어로 말합니다.

⚠️ Code 탭은 유료 요금제(Pro · Max · Team · Enterprise)에서만 열립니다. 누르자마자 업그레이드 안내가 뜨면 무료 계정입니다.

💡 화면이 업데이트로 바뀌어 버튼을 못 찾겠으면, Code 탭 안에서 "작업 폴더를 바꾸려면 어떻게 해?"라고 물어보세요. 13차시와 같은 요령입니다.

Claude Code는 '허락'을 구합니다

수동 모드의 Claude Code는 파일을 고치거나 명령을 실행하기 전에 "이걸 해도 될까요?"라고 묻습니다. 처음엔 번거롭지만, 이게 안전장치입니다. 얼마나 자주 물을지는 권한 모드로 정합니다.

권한 모드묻지 않고 하는 일언제
수동파일 읽기만오늘 수업 · 처음 쓸 때 · 중요한 자료
편집 자동 수락읽기 + 파일 고치기·만들기익숙해진 뒤, 결과만 확인하고 싶을 때
계획읽고 둘러보기만 — 고치지 않고 계획만 세움큰 일을 시키기 전
자동거의 전부 (위험해 보이는 것만 자동으로 막음)오래 걸리는 일 — 요금제에 따라 안 보일 수 있고, 이 과정에선 쓰지 않음

수동에서 허락 요청이 오면 이렇게 판단합니다.

Claude Code가 물을 때이렇게 판단
파일 읽기묻지 않음 — 작업 폴더 안 파일은 그냥 읽습니다
새 파일 만들기 · 파일 고치기무슨 파일인지 보고 허락
명령 실행 (프로그램 돌리기)무슨 명령인지 모르겠으면 "이 명령이 뭘 하는지 쉽게 설명해줘"라고 먼저 묻기
파일 지우기 · 폴더 밖 작업멈추고 이유를 묻기 — 실습에선 허락하지 않는다

계획 먼저 — 13차시 습관 그대로

큰 일을 시킬 땐 "진행 전에 계획 먼저 보여줘"를 붙이세요. 위 표의 계획 모드로 바꿔도 같습니다 — 계획만 세우고 파일은 건드리지 않다가, 계획을 승인해야 움직입니다. 이 수업에서는 모드를 바꾸지 않고 말로 "계획 먼저"를 붙이는 방식으로 갑니다.

⚠️ Claude Code 안전 수칙 3가지 — 다음 차시에도 그대로
  1. 연습은 복사본 폴더에서 — 원본은 넣지 않는다.
  2. 실행 전에 계획 확인 — 무엇을 읽고, 어디에 쓰고, 원본을 건드리는지.
  3. 결과는 원본과 대조 — 특히 처음 만든 도구.

② 무엇이 있는지 묻기

"이 폴더에 뭐가 있는지 보여주고, 엑셀 파일의 시트 이름과 각 시트의 열 이름을 표로 정리해줘. 아직 아무것도 고치거나 만들지 마."

💡 메모장 파일은 그냥 읽지만, 엑셀은 열어 보는 명령을 실행해야 읽을 수 있습니다. 그래서 여기서 명령 실행 허락을 물을 수 있어요. 한 줄 설명을 읽고 허락합니다. PC에 Python이 없으면 "Python이 없어서 PowerShell로 읽겠습니다"처럼 다른 방법을 스스로 찾기도 하는데, 정상입니다.

✅ 확인할 것 — 시트 2개, 열 5개가 나왔나?

채널별_이번주 시트에 유입채널 · 방문자수 · 주문건수 · 매출비중(%) · 전주 매출비중(%), 사용법 시트에 설명 글이 있다고 나오면 정상입니다. 끝에 "도구를 만들까요?" 버튼이 뜨면 '아직 괜찮아' — 도구는 규칙(실습 B)부터 정하고 만듭니다.

③ 13차시와 비교

지난 시간 앱에서 폴더를 연결했을 때와 무엇이 같고 무엇이 다른지 옆 사람과 한 줄씩 말해 봅니다. (힌트: 허락을 묻는 방식, 결과가 생기는 곳, 화면 생김새)

CLAUDE.md — 폴더에 두는 '항상 지킬 규칙'

13차시에선 규칙을 안내_읽어주세요.txt에 적고 매번 "읽어라"고 말했습니다. Claude Code에는 더 편한 방법이 있습니다. 폴더에 CLAUDE.md라는 이름의 파일을 두면, 그 폴더를 열 때마다 Claude Code가 자동으로 먼저 읽습니다.

CLAUDE.md에 넣기 좋은 것예
이 폴더가 무엇인지"그린컵 마케팅팀 주간 실적 폴더"
항상 지킬 규칙"원본 엑셀은 절대 고치지 않는다. 결과는 결과/ 폴더에."
회사 기준"비중(%)은 소수점 첫째 자리까지. 주는 월요일 시작."
설명 방식"나는 비개발자다. 명령을 실행하기 전에 무엇을 하는지 한 줄로 설명해라."

💡 직접 쓸 필요도 없습니다. "방금 정한 규칙들을 CLAUDE.md로 저장해줘"라고 말하면 됩니다. 다만 어떤 내용이 들어갔는지는 꼭 열어서 읽어 보세요. 이 파일이 앞으로 모든 대화의 배경이 됩니다.

③ 새 대화에서 적용 확인

Code 탭에서 새 대화를 열고 같은 폴더를 고릅니다. 같은 대화에서 물으면 방금 만든 내용을 기억해서 답하기 때문에, 자동으로 읽혔는지 확인하려면 새 대화여야 합니다.

"이 폴더에서 지켜야 할 규칙이 뭐야?"

✅ 확인할 것 — 말 안 해도 알고 있나?

규칙을 다시 말해 주지 않았는데 여섯 가지를 답하면 CLAUDE.md가 자동으로 읽힌 겁니다. 13차시의 "매번 안내 파일 읽어라"가 필요 없어졌죠.

첫 도구 만들기 — '결과'가 아니라 '기계'를 받는다

이제 오늘의 핵심입니다. 13차시 주간보고 초안에서 [실적 집계 예정]으로 비워 둔 칸, 기억하시죠? 매주 같은 계산이라 Claude Code 몫으로 남겨 둔 단계입니다. 앱에 "매출비중 상위 3개 채널을 뽑아줘"라고 하면 숫자만 받습니다. 오늘은 "그 계산을 하는 프로그램을 만들어줘"라고 합니다.

"계산해줘""계산하는 도구를 만들어줘"
받는 것이번 주 숫자숫자 + 프로그램 파일
다음 주다시 부탁 → AI가 다시 계산프로그램만 다시 실행 → 같은 방식으로 계산
틀렸을 때매번 검수처음 몇 번 검수하면, 이후엔 로직이 안 변함

좋은 도구 요청문의 네 가지

  1. 입력 — 어떤 파일을 읽나 ("이름에 channel_performance가 들어간 엑셀")
  2. 처리 — 무엇을 계산하나 ("매출비중 상위 3개, 전주보다 3%p 이상 변한 채널 표시")
  3. 출력 — 결과를 어디에 어떤 형식으로 ("결과/채널집계.csv")
  4. 예외 — 이상한 파일을 만나면 ("빈 칸·깨진 행은 건너뛰고 로그에 남겨")

💡 마지막에 "나는 비개발자니까 다음 주에 다시 실행하는 방법도 알려줘"를 꼭 붙이세요. 도구는 다시 쓸 수 있어야 의미가 있습니다.

  • 실적도구 폴더 · 엑셀 + CLAUDE.md

① 계획 받기

"이 폴더에서 이름에 channel_performance가 들어간 엑셀 중 가장 최근 파일 하나를 읽어서, 엑셀의 '사용법' 시트에 적힌 대로 ① 매출비중 상위 3개 채널을 뽑고 ② 전주 매출비중보다 3%p 이상 변한 채널을 표시해 결과/채널집계.csv로 저장하는 도구를 만들어줘. 추가 설치 없이 이 PC에서 바로 돌아가게 만들어. 빈 칸이나 숫자가 아닌 칸이 있는 행은 건너뛰고 결과/처리로그.txt에 남겨. 다음 주엔 새 엑셀만 넣고 다시 실행할 수 있게. 진행 전에 계획 먼저 보여줘."

💡 3%p(퍼센트포인트) = 비중 숫자끼리의 차이가 3 이상이라는 뜻입니다. 예: 전주 20% → 이번 주 23.5%면 3.5%p 변한 것.

✅ 확인할 것 — 계획에 이 세 가지가 있나?

어떤 파일을 읽는지, 결과를 결과/ 폴더에 쓰는지(CLAUDE.md 규칙), 원본 엑셀을 고치지 않는지. 셋 다 있으면 "좋아, 진행해". 요청에 없던 규칙을 Claude Code가 먼저 꺼냈다면 CLAUDE.md가 일하고 있다는 뜻입니다.

② 만들고 실행

Claude Code가 프로그램 파일을 만들고 실행해도 되는지 물으면, 무엇을 하는 명령인지 한 줄 설명을 읽고 허락합니다. 끝나면 탐색기에서 도구 파일(Python이 없는 PC면 .ps1 같은 파일)이 폴더에 생겼는지 보고, 결과/채널집계.csv를 열어 봅니다.

③ 원본과 대조

"방금 도구가 뽑은 상위 3개 채널과 3%p 이상 변한 채널이 맞는지, 도구를 쓰지 말고 엑셀 원본 숫자로 직접 다시 확인해서 대조표로 보여줘."

✅ 확인할 것 — 대조표가 전부 일치하나?

여러분도 엑셀을 열어 매출비중이 큰 3개와 전주와 3 이상 차이 나는 채널을 직접 찾아보세요. 6줄뿐이라 1분이면 됩니다. 도구는 처음 한 번이 가장 중요합니다. 여기서 맞으면 다음 주부터는 로직이 안 변합니다.

④ 다음 주 시뮬레이션

"다음 주 엑셀이라고 치고, 상위 3개 순서가 바뀌도록 숫자만 조금 바꾼 샘플 파일을 channel_performance_다음주.xlsx라는 이름으로 원본 엑셀과 같은 위치(결과/ 폴더 말고)에 하나 만들어줘. 원본 엑셀은 그대로 둬. 그다음 방금 만든 도구를 다시 실행해서 결과를 갱신해줘. 마지막으로 이 도구를 다시 실행하는 법을 비개발자용 3줄로 사용법.txt에 저장해줘."

✅ 확인할 것 — '새로 계산'이 아니라 '다시 실행'이었나?

Claude Code가 계산을 새로 짜지 않고 같은 프로그램을 다시 돌렸는지 보세요. 그리고 결과의 상위 3개가 다음 주 파일 숫자대로 바뀌었는지도요. 이게 오늘의 핵심 — 새 데이터, 실행 한 번, 같은 로직입니다.

📌 4절 한 줄 요약

"계산해줘" 대신 "계산하는 도구를 만들어줘". 입력 · 처리 · 출력 · 예외를 말하고, 첫 회차는 반드시 원본과 대조한다.

자주 묻는 질문

Q. 터미널(검은 창)은 안 써도 되나요?
A. 오늘은 앱의 Code 탭만 씁니다. 같은 Claude Code를 터미널이나 VS Code에서도 쓸 수 있는데, 하는 일은 같습니다.

Q. Claude Code가 만든 프로그램 파일은 열어 봐야 하나요?
A. 읽을 줄 몰라도 괜찮습니다. 대신 원본과 대조한 결과와 사용법.txt는 꼭 확인하세요. 궁금하면 "이 프로그램이 하는 일을 순서대로 5줄로 설명해줘".

Q. 그럼 이제 다 Claude Code로 하면 되나요?
A. 아닙니다. 판단이 섞인 정리·취합·작성은 여전히 앱에 맡기는 게 편합니다. 매번 똑같아야 하는 계산만 Code로 굳히세요.

Q. 무료 계정인데 따라 할 수 있나요?
A. Code 탭은 유료 요금제(Pro 이상)에서만 열립니다. 오늘은 강사 화면으로 흐름을 보고, 1절의 판별 질문과 '내 업무라면?'의 네 줄 정리는 그대로 해 두세요.

Q. 회사 PC에서 써도 되나요?
A. 프로그램을 실행하는 도구라 회사 보안 정책을 먼저 확인하세요. 실습은 개인 PC의 복사본 폴더로 합니다.

오늘 정리

📌 세 개만 기억하기
  1. 앱은 일을 해 주고, Code는 그 일을 하는 기계를 만든다.
  2. CLAUDE.md = 폴더를 열면 자동으로 읽히는 규칙.
  3. "계산해줘"가 아니라 "계산하는 도구를 만들어줘" — 첫 회차는 원본 대조.

전체 정리

  • 폴더 맡기기는 결과물, Claude Code는 결과물 + 다시 돌릴 프로그램. 갈림길은 "매번 완전히 똑같아야 하는가".
  • Code 탭은 유료 요금제에서 열리고, 내 폴더를 쓰려면 환경을 Local로.
  • 권한 모드는 오늘 수동 — 읽기는 안 묻고, 고치기·명령 실행은 묻는다. 모르는 명령은 설명부터.
  • 항상 지킬 규칙은 폴더의 CLAUDE.md에. 새 대화를 열 때마다 자동으로 읽힌다.
  • 도구 요청은 입력 · 처리 · 출력 · 예외 + "다시 실행하는 법". 첫 결과는 원본과 대조.
  • 다음 주엔 새 파일 넣고 같은 도구 실행 — 새로 계산시키지 않는다.
