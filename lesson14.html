원리 — 앱과 무엇이 다른가

🧭 한 줄로 기억하기

앱은 일을 해 주고, Claude Code는 그 일을 하는 '기계(프로그램)'를 만들어 준다.

폴더 맡기기 (13차시 앱)Claude Code
남는 것결과물결과물 + 다시 돌릴 수 있는 프로그램
다음 주 같은 일AI가 다시 판단 → 조금씩 다를 수 있음같은 프로그램 실행 → 같은 방식으로 계산
폴더 규칙안내 파일 (매번 "읽어라")CLAUDE.md — 폴더를 열면 자동으로 읽힘
어울리는 일정리·요약·초안 (판단이 섞인 일)집계·변환 (매번 똑같아야 하는 일)

권한 모드 — 얼마나 자주 허락을 물을까

수동에서는 읽기는 묻지 않고, 파일을 만들거나 고치거나 명령을 실행할 때마다 묻습니다. 오늘은 무엇을 하는지 하나하나 보는 게 목표라 수동으로 갑니다. 익숙해지면 편집 자동 수락(고치기까지 자동), 큰 일 전엔 계획(계획만 세우고 고치지 않음)을 씁니다. 모르는 명령이 나오면 "이 명령이 뭘 하는지 쉽게 설명해줘"부터 묻습니다. 파일 지우기·폴더 밖 작업은 실습에서 허락하지 않습니다.

CLAUDE.md — 폴더에 두는 '항상 지킬 규칙'

폴더에 CLAUDE.md라는 파일을 두면 그 폴더를 열 때마다 Claude Code가 자동으로 먼저 읽습니다. 원본 수정 금지, 결과 저장 위치, 소수점 자리 같은 규칙을 한 번만 적어 두면 됩니다. 직접 쓸 필요 없이 말로 만들게 하고, 내용만 열어서 확인합니다.

"계산해줘" 대신 "계산하는 도구를 만들어줘"

좋은 도구 요청문에는 네 가지가 들어갑니다.

  1. 입력 — 어떤 파일을 읽나
  2. 처리 — 무엇을 계산하나
  3. 출력 — 결과를 어디에 어떤 형식으로
  4. 예외 — 이상한 데이터를 만나면
⚠️ 안전 수칙 3가지
  1. 연습은 복사본 폴더에서
  2. 실행 전에 계획 확인 — 무엇을 읽고, 어디에 쓰고, 원본을 건드리는지
  3. 처음 만든 도구는 원본과 대조

실습 — 규칙 파일과 첫 도구

🛠 실습 B — CLAUDE.md 만들고 주간 채널 분석 도구 만들기

순서는 ① CLAUDE.md 만들기 → ② 새 대화에서 계획 받기 → ③ 만들고 실행 → ④ 원본과 대조.
①은 실습 A와 같은 대화, ②부터는 새 대화에서 이어갑니다.

📎 준비물
  • 실습 A의 실적도구 폴더 · Code 탭에 연결돼 있음

① CLAUDE.md 만들기

"이 폴더에 CLAUDE.md를 만들어줘. 내용: ① 이 폴더는 그린컵 마케팅팀 주간 채널 실적 폴더다 ② 원본 엑셀은 절대 고치지 않는다 ③ 결과 파일은 결과/ 폴더에 저장한다 ④ 나는 비개발자이니 명령을 실행하기 전에 무엇을 하는지 한 줄로 쉽게 설명한다 ⑤ 비중(%)은 소수점 첫째 자리까지 ⑥ csv는 엑셀로 열어도 한글이 깨지지 않게 저장한다."

탐색기에서 CLAUDE.md를 오른쪽 클릭 → 연결 프로그램 → 메모장으로 열어 여섯 줄이 다 들어갔는지 봅니다.

② 새 대화에서 계획 받기

Code 탭에서 새 대화를 열고 같은 폴더를 고릅니다. 규칙을 다시 말하지 않고 바로 요청합니다.

"이 폴더에서 이름에 channel_performance가 들어간 엑셀 중 가장 최근 파일 하나를 읽어서, ① 매출비중 상위 3개 채널을 뽑고 ② 전주 매출비중보다 3%p 이상 변한 채널을 표시해 결과/채널집계.csv로 저장하는 도구를 만들어줘. 추가 설치 없이 이 PC에서 바로 돌아가게. 빈 칸이나 숫자가 아닌 칸이 있는 행은 건너뛰고 결과/처리로그.txt에 남겨. 다시 실행하는 법은 사용법.txt에 3줄로. 진행 전에 계획 먼저 보여줘."

💡 3%p = 비중 숫자끼리의 차이가 3 이상. 예: 전주 20% → 이번 주 23.5%면 3.5%p 변한 것.

✅ 확인할 것 — 말 안 한 규칙이 계획에 있나?

계획에 "원본은 고치지 않음", "결과/ 폴더에 저장" 같은 말이 나오면 CLAUDE.md가 자동으로 읽힌 겁니다. 확인되면 "좋아, 진행해".

③ 만들고 실행

허락 요청마다 한 줄 설명을 읽고 허락합니다. 끝나면 탐색기에서 도구 파일(Python이 없는 PC면 .ps1 같은 파일)과 결과/채널집계.csv가 생겼는지 봅니다.

④ 원본과 대조

"방금 도구가 뽑은 상위 3개 채널과 3%p 이상 변한 채널이 맞는지, 도구를 쓰지 말고 엑셀 원본 숫자로 직접 다시 확인해서 대조표로 보여줘."

✅ 확인할 것 — 대조표가 전부 일치하나?

엑셀을 직접 열어 매출비중이 큰 3개도 찾아보세요. 6줄뿐이라 1분이면 됩니다. 처음 한 번이 맞으면, 다음 주부터는 새 파일 넣고 같은 도구를 실행만 하면 됩니다.

📌 PART 1 한 줄 요약

매번 똑같아야 하는 계산은 "계산하는 도구를 만들어줘" — 입력·처리·출력·예외를 말하고, 규칙은 CLAUDE.md에, 첫 결과는 원본과 대조.

연결 — Claude에 업리카 붙이기

업리카(uplika)는 Claude에 연결해 네이버 블로그·인스타그램 같은 내 채널에 글을 대신 올려 주는 서비스입니다. 연결 방식은 6차시에 배운 MCP(커넥터)이고, 2026년 11월 현재 베타 기간이라 무료입니다(정식 요금은 바뀔 수 있음).

💡 블로그는 Code로도 됩니다. 같은 Claude 앱의 업리카 커넥터라 Code 탭에서도 쓸 수 있고, 실습 B의 CLAUDE.md 규칙도 그대로 적용됩니다. 다만 Code는 "매번 똑같이 돌려야 하는 계산"에 가장 잘 맞고, 블로그는 판단이 많은 일이라 오늘은 대화(Project)로 진행합니다.

🛠 실습 C — 업리카 커넥터 연결하기

순서는 ① 업리카 가입·네이버 연결 → ② Claude에 커넥터 추가 → ③ 연결 확인.
③은 그린컵 Project 안에서 새 대화를 열고, 실습 D까지 한 대화에서 이어갑니다.

📎 준비물
  • 네이버 아이디 · 블로그는 아이디마다 자동으로 있음
  • 크롬 · 업리카 확장을 설치할 브라우저 (엣지·웨일도 가능)

① 업리카 가입·네이버 연결

업리카 가입 → 연결 화면에서 네이버 블로그를 고르고, 안내대로 크롬 확장을 설치한 뒤 네이버에 로그인합니다.

② Claude에 커넥터 추가

이름: uplika URL : https://api.uplika.com/mcp

💡 "외부 링크에서 제안되었습니다" 경고는 정상입니다. 주소가 api.uplika.com인지만 확인하세요.

③ 연결 확인

"업리카에 연결된 내 계정 목록과 네이버 확장 상태를 알려줘. 내 블로그 카테고리 목록도 보여줘."

✅ 확인할 것 — 네이버 블로그 '활성', 확장 '켜짐'인가?

둘 다 보이면 성공입니다. 확장이 꺼져 있다고 나오면 확장을 설치한 크롬을 켜고 1분 뒤 다시 물어보세요. 카테고리 이름은 실습 D ④에서 씁니다.

원리 — 크롬 확장, 키워드, 글의 모양

왜 크롬이 켜져 있어야 하나

네이버 블로그에는 다른 회사가 글을 넣는 공식 통로(API)가 없습니다. 그래서 업리카는 내 크롬에 설치한 확장이 내 대신 네이버 글쓰기 화면에 글을 넣습니다.

하는 일크롬이 켜져 있어야 하나?
키워드 조사 · 글 쓰기 · 미리보기아니요 — 업리카 서버에서 처리
임시저장 · 발행 · 예약 발행예 — 내 크롬의 확장이 네이버에 직접 씀

예약 발행은 그 시간에 크롬이 켜져 있어야 나갑니다. 꺼져 있으면 켜질 때까지 최대 7일 기다립니다.

키워드 — 세 숫자와 두 가지 함정

숫자뜻
월간 검색량한 달에 네이버에서 검색된 횟수 = 찾는 사람
블로그 문서 수그 키워드로 이미 쓰인 글 수 = 경쟁자
비율검색량 ÷ 문서 수 — 높을수록 기회
  • ⛔ 벽 — 찾는 사람은 많지만 글이 너무 많아 새 블로그는 뚫기 어려움 (예: "클로드 사용법" 월 3,510회, 문서 약 12만 — 2026년 11월 측정)
  • 👻 유령 — 검색이 거의 없어 1등을 해도 아무도 안 옴

그래서 새 블로그는 "클로드 사용법" 대신 "클로드 코워크 차이"처럼 구체적인 세부 키워드를 노립니다. 이런 키워드는 월 검색량이 수십 회 수준일 수 있고, 벽도 유령도 아닌데 '어려움'(노랑)으로 나오는 것도 있습니다 — 후보로 쓸 수 있지만 경쟁이 있다는 뜻으로 읽으세요. 판정은 AI가 하고, 고르는 건 사람입니다 — 내가 직접 겪어 쓸 수 있는 주제만 고릅니다.

검색에 걸리는 글의 모양

  • 메인 키워드는 제목 앞쪽과 첫 문단 첫 줄에, 본문 3~5회, 태그에
  • 첫 문단에 누가 · 어떤 상황에서 · 왜 이 글을 찾는지 한 줄 (네이버 AI 브리핑 가이드)
  • 과정은 실제로 한 순서대로, 결과와 아쉬운 점까지
⚠️ 없는 경험은 지어내지 않습니다

AI는 그럴듯한 경험담을 쉽게 지어냅니다. 그래서 내 경험 메모를 주고, 모르는 건 [확인필요]로 남기게 합니다.

같은 글도 네이버 블로그 양식에 따라 소제목·구분선·사진 배치가 달라집니다. 업리카에는 양식이 8가지 있고, 순서대로 따라 하는 기록 글에는 구분선 튜토리얼형이 잘 맞습니다.

  • 실습 C ③에서 본 카테고리 이름 · 같은 대화에 있음

① 키워드 판정·주제 고르기

"업리카로 '클로드', '클로드 코드', '업무 자동화'를 네이버 자동완성으로 넓히고, 'AI로 업무를 자동화하며 배운 것을 기록하는 블로그'에 맞는 10개를 골라 검색량·블로그 문서 수·판정을 표로 보여줘. 그다음 벽·유령이 아닌 메인 키워드로 글 주제 3개를 제안하고, 주제마다 서브 키워드 2개와 고른 이유를 붙여줘. 내 경험은 이거야: ① 폴더째 맡기기로 주간보고 초안을 만들어 봤다 ② Claude Code로 채널별 실적 분석 도구를 만들고 원본과 대조했다 ③ 업리카를 Claude에 연결하고 네이버 블로그 카테고리를 확인했다. 내가 하나 고를 때까지 글은 쓰지 마."

✏️ 노란 칸은 내 이야기로 바꿔 쓰는 자리입니다. 위 문장은 예시이니, 이 과정에서 내가 실제로 해 본 것 3~5줄로 바꿔 넣으세요. 하지 않은 일은 쓰지 않습니다 — 여기 적은 것만 글의 경험이 됩니다.

💡 "일부만 측정됐다"고 나오면 "같은 키워드로 한 번 더 재서 채워줘". 측정 결과는 업리카에 7일간 저장돼서, 반 전체가 같은 키워드를 쓰면 금방 나옵니다.

✅ 확인할 것 — 내가 직접 겪은 걸로 쓸 수 있나?

메인 키워드가 벽·유령이 아닌지 표에서 보고, 내 경험으로 쓸 수 있는 주제를 "2번으로 할게"처럼 고릅니다.

② 글 쓰기·검수

"고른 주제로, 업리카 키워드 조사에서 받은 글쓰기 지시문을 따라 블로그 글을 써줘. 800~1,000자, 존댓말. 내 경험 메모에 있는 것만 경험으로 쓰고, 없는 경험·숫자는 지어내지 말고 [확인필요]로 남겨."

✅ 확인할 것 — 내가 하지 않은 일이 적혀 있지 않나?
  • 경험담이 전부 내가 실제로 한 것인가?
  • 메인 키워드가 제목 앞쪽과 첫 줄에 있나?
  • [확인필요] 자리를 채우거나 지웠나?

③ 양식 고르기

"이 글을 업리카 미리보기로 '사진 이야기형', '구분선 튜토리얼형', '표 설명형' 세 양식에 넣어 나란히 보여줘. 글은 그대로 두고, 아직 저장하지 마."

마음에 드는 양식 하나를 "구분선 튜토리얼형으로 할게"처럼 내가 고릅니다.

④ 지금 비공개로 발행

"이 글을 고른 양식으로 지금 바로 '비공개'로 발행해줘. 카테고리는 [내 카테고리]. 발행하기 전에 제목·카테고리·태그·공개 범위를 한 번에 보여주고, 내가 OK하면 발행해."

✅ 확인할 것 — 내 블로그에 비공개로 올라왔나?

발행이 끝났다고 하면 내 블로그를 엽니다(비공개라 나에게만 보임). 발행은 내 크롬의 확장이 하니 크롬이 켜져 있어야 합니다. 안 올라왔으면 크롬을 확인하고 "방금 발행한 글 상태 알려줘".

📌 PART 2 — 사람이 판단한 자리 4곳

① 주제 고르기 → ② 글 검수 → ③ 양식 고르기 → ④ 발행 승인. 조사·작성·발행은 AI가, 이 네 자리는 사람이 맡습니다.

마스터 프롬프트

도구 만들기 (Claude Code)

이 폴더의 [입력 파일 — 이름 패턴]을 읽어서 [무엇을 계산·변환]해 [결과 파일 경로·형식]으로 저장하는 도구를 만들어줘. 빈 파일이나 형식이 깨진 데이터는 건너뛰고 [로그 파일]에 이유와 함께 남겨. 원본 파일은 고치지 마. 다시 실행하는 방법을 사용법.txt에 3줄로 남겨줘. 진행 전에 계획 먼저 보여줘.

블로그 한 편 (업리카 — Project 지침에 넣어 두면 매번 같은 순서로 진행)

너는 내 네이버 블로그 글쓰기 도우미야. 업리카를 써서 아래 순서로 진행하고, 각 단계가 끝나면 반드시 멈추고 내 확인을 받아. 1. 키워드: [시드 키워드 2~3개]를 자동완성으로 넓혀 10개의 검색량·문서 수·판정을 표로 2. 주제: 벽·유령이 아닌 메인 키워드로 주제 3개 + 서브 키워드 + 이유 → 내가 고름 3. 글: 지시문대로 800~1,000자. 경험은 [내 경험 메모]에 있는 것만, 모르면 [확인필요] → 내가 검수 4. 양식: 미리보기로 나란히, 글은 그대로 → 내가 고름 5. 발행: 제목·카테고리·태그·공개 범위를 보여주고 내가 OK하면 실행 블로그 주제: [AI로 업무를 자동화하며 배운 것을 기록]

자주 묻는 질문

Q. 코딩을 몰라도 Claude Code를 쓸 수 있나요?
A. 됩니다. 코드는 Claude Code가 씁니다. 우리가 쓰는 건 무엇을, 어떤 순서로 할지 말하고 결과를 검수하는 실력입니다.

Q. AI가 쓴 글을 블로그에 올려도 괜찮나요?
A. 핵심은 내 경험과 내 검수입니다. 검수 없이 같은 형식의 글을 대량으로 올리는 건 품질 면에서도, 네이버 운영 정책 면에서도 위험합니다.

Q. 오늘 만든 도구 이야기를 블로그에 써도 되나요?
A. 좋습니다. 오늘 실제로 한 일이라 그대로 경험 메모가 됩니다.
