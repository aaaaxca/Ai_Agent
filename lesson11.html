초보가 가장 많이 하는 실수가 규칙을 통째로 붙이고 "다 만들어줘" 입니다. 뭔가 나오긴 하는데, 어디가 틀렸는지 알 수 없습니다.

2-1. 네 단계로

단계무엇왜
① 규칙을 붙인다계산 규칙 문서를 그대로 첨부말로 옮기면 반드시 빠뜨립니다
② 뼈대만 만든다기본가 × 수량만 되는 계산기여기가 맞아야 나머지가 의미 있음
③ 하나씩 붙인다옵션 → 수량 할인 → 추가 할인 → 배송 → 부가세한 번에 하나씩. 틀리면 방금 붙인 게 범인

💡 ③의 "한 번에 하나씩"이 핵심입니다. 다섯 개를 한꺼번에 붙이고 결과가 틀리면 다섯 개를 다 뒤져야 해요. 하나씩 붙이면 범인은 항상 방금 그것입니다.

⚠️ ④를 건너뛰지 마세요. 아티팩트는 결과가 너무 그럴듯하게 나옵니다. 화면이 깔끔하고 숫자가 딱 떨어지니 맞는 것 같죠. 8차시에서 배운 그 문제 — 그럴듯함이 정확함은 아닙니다.

① 규칙 문서 붙이고 뼈대만 시키기

파일을 첨부하고 아래를 입력합니다. 1번과 3번만 시키는 게 포인트예요.

"이 견적 규칙 문서를 읽고, 단체주문 견적 계산기를 만들려고 해. 지금은 1번(기본 단가)과 3번(수량 할인)만 반영해줘. 나머지는 나중에 붙일 거야. 제품을 고르고 수량을 넣으면 소계와 할인이 적용된 금액이 나오게. 숫자를 바꾸면 바로 반영되게."

② 경계값 넣어 보기

수량칸에 20, 99, 100을 차례로 넣어 봅니다.

✅ 확인할 것 — 제품 4종, 할인 4단계, 100개에서 8%?
  • 제품 4종이 다 들어갔나 (350ml · 500ml · 보온병 500 · 750)
  • 수량 할인 구간이 4단계인가 (50 · 100 · 300 · 500)
  • 20개일 때 할인 0%, 100개일 때 8%인가 (5%가 아니라)

💡 마지막 항목이 함정입니다. 규칙은 "100개 이상 8%" 인데, 구간을 '초과'로 잡으면 100개에서 5%가 나옵니다. 8차시에서 배운 경계값 검증이 여기서 또 나와요.

📖 경계값 : 구간이 바뀌는 바로 그 숫자(100개, 100만원). '이상'인지 '초과'인지에 따라 결과가 갈려서 가장 자주 틀립니다

공유 — 누가 열 수 있고, 사용량은 누가 내나

만든 도구를 팀원에게 넘기려면 공유해야 합니다. 그런데 2026년 9월 16일 아티팩트가 새로 바뀌면서 공유 방식도 달라졌어요. 예전 자료에서 본 내용과 다를 수 있으니 이 절을 기준으로 하세요.

4-1. 기본은 '나만 보기'

새로 만든 아티팩트는 처음엔 나만 볼 수 있습니다. 공유하기 전까지는 아무에게도 안 보여요. 아티팩트를 열고 '공유'(Share) 버튼 → '접근 권한'(Who has access)에서 고릅니다.

플랜고를 수 있는 공유 범위
Free새 아티팩트는 링크 공유가 안 됩니다 → 7절의 HTML 배포가 대안입니다
Pro · Max나만 / 이메일로 특정인 초대(베타) / 링크가 있는 모든 사람
Team · Enterprise특정인 / 조직 전체. 조직 밖 공유는 관리자가 허용해야 됩니다
⚠️ 링크를 받은 사람도 Claude에 로그인해야 열립니다.

'링크가 있는 모든 사람'은 Claude 계정으로 로그인한 사람 중 링크를 가진 누구나라는 뜻이에요. 계정이 없는 고객이나 거래처에게 링크만 주면 못 엽니다. 그럴 때가 바로 7절(배포)이 필요한 순간입니다.

HTML로 꺼내서 배포하기

지금까지 만든 도구는 Claude 안에 있습니다. 그래서 여는 사람도 Claude 계정이 필요했죠(4절). 이번엔 도구를 파일 하나로 꺼내서, 계정 없이 누구나 주소로 여는 웹페이지로 올립니다. "만들 줄 안다"에서 "배포할 줄 안다"로 넘어가는 단계예요.

7-1. 단어 셋만 알고 가면 됩니다

📖 HTML : 웹페이지를 이루는 파일. 오늘 만든 계산기도 속은 HTML 파일 한 장입니다. 더블클릭하면 인터넷 창으로 열려요
📖 배포 : 내 컴퓨터에만 있던 파일을 인터넷 주소로 누구나 열 수 있게 올리는 것
📖 GitHub Pages : GitHub(코드 보관 사이트)가 주는 무료 웹페이지 호스팅. 파일을 올리면 내아이디.github.io/저장소이름/ 주소가 생깁니다

7-2. Claude 공유 링크 vs 배포 — 뭐가 다른가

Claude 공유 링크GitHub Pages 배포
여는 사람Claude 로그인 필요아무나 (계정 필요 없음)
Free 플랜새 아티팩트는 링크 공유 ✗됩니다
AI 부르기·저장 기능됩니다안 됩니다 (5절)
고치면바로 반영파일을 다시 올려야 반영
공개 범위내가 고른 범위인터넷 전체 공개 ⚠️

⚠️ 배포는 공유보다 더 넓은 공개입니다. 주소만 알면 검색으로도 들어올 수 있고, 무료로 쓰려면 저장소를 Public(공개)으로 만들어야 해서 파일 내용까지 누구나 볼 수 있습니다. 실제 단가·고객 정보가 든 도구는 배포하지 마세요.

7-3. 폴더를 이렇게 맞춥니다

결과물 여러 개를 사이트 하나로 묶습니다. 첫 화면(목차) 하나에, 실습마다 폴더 하나씩.

my-tools/ ← 저장소 하나 ├── index.html ← 첫 화면: 카드형 목차 ├── practice1/ │ └── index.html ← 견적 계산기 (실습 B~D) ├── practice2/ │ └── index.html ← 회의록 리포트 (실습 H) └── practice3/ └── index.html ← 설문 대시보드 (실습 F)
💡 왜 전부 이름이 index.html인가요?

웹 주소가 폴더에서 끝나면(…/practice1/) 그 폴더의 index.html을 자동으로 엽니다. 그래서 파일 이름을 index.html로 바꿔 두면 주소가 짧고 깔끔해져요. 이 과정 홈페이지(aaaaxca.github.io/Ai_Agent/)도 같은 방식입니다.

자주 묻는 질문 (FAQ)

Q. 코드를 몰라도 정말 되나요? A. 됩니다. 오늘 코드를 한 줄도 안 씁니다. 다만 규칙을 정확히 말할 수 있어야 해요. 필요한 건 코딩 능력이 아니라 업무를 정확히 설명하는 능력 — 2차시에서 배운 그것입니다.

Q. 만든 도구가 사라지지 않나요? A. 사이드바 '아티팩트' 탭에 남습니다. 중요한 도구는 HTML 파일로도 받아 두면(8-3) 더 안전해요.

Q. 무료 플랜에서도 되나요? A. 만드는 건 됩니다 (실습 A~F, H). 다만 새 아티팩트를 링크로 공유하는 건 Pro 이상이라, 무료 플랜은 실습 I의 GitHub Pages 배포로 공유하면 됩니다. 입력한 기록을 저장하는 기능도 Pro 이상입니다.

Q. 예전에는 '게시(Publish)'하면 로그인 없이 볼 수 있었다던데요? A. 2026년 9월 16일 전에 만든 예전 방식 아티팩트 이야기입니다. 예전 것은 지금도 게시할 수 있지만, 새로 만드는 아티팩트는 오늘 배운 방식(나만 → 공유 범위 선택)을 따릅니다.

Q. 엑셀로 하면 되는 걸 왜 아티팩트로 하나요? A. 갈리는 지점은 누가 쓰느냐입니다. 나만 쓰면 엑셀이 편해요. 남에게 넘겨야 하면 아티팩트가 낫습니다 — 엑셀은 남이 열면 수식을 건드리거나 깨뜨리거든요. 데이터가 매일 바뀌면 엑셀(23차시), 규칙이 고정이면 아티팩트입니다.

Q. 회사 데이터를 넣어도 되나요? A. 나만 보는 상태라면 일반 대화와 같은 수준입니다. 회사 AI 사용 정책을 따르세요. 다만 공유·배포하는 순간 범위가 넓어집니다. 특히 GitHub Pages는 인터넷 전체 공개예요.

Q. 결과가 그럴듯한데 맞는지 어떻게 알죠? A. 손으로 낸 결과와 대조하는 것 말고는 없습니다. 실습 D가 그래서 있어요. 화면이 깔끔한 것과 숫자가 맞는 건 전혀 다른 얘기입니다.

Q. GitHub에 올린 파일, 다른 사람이 고칠 수 있나요? A. 못 고칩니다. 보거나 내려받을 수는 있지만, 저장소를 고칠 수 있는 건 나(와 내가 초대한 사람)뿐입니다. 대신 내용은 누구나 볼 수 있으니 민감한 건 올리지 마세요.

Q. Private(비공개) 저장소로 하면 안 되나요? A. 무료 계정에서는 Public 저장소만 Pages가 무료입니다. 비공개 저장소로 Pages를 쓰려면 유료 플랜이 필요해요.

오늘 정리

🎯 세 개만 기억한다면

  1. 아티팩트는 답이 아니라 물건 — 남고, 넘기고, 고쳐 쓴다
  2. 뼈대 → 하나씩 → 검산 — 한 번에 다 만들면 어디가 틀렸는지 모른다
  3. 공유는 범위를 고르고, 배포는 전체 공개 — 민감한 정보는 넣지 않는다

전체 정리

  • 10차시까지는 AI에게 일을 시켰다. 오늘은 AI에게 도구를 만들게 했다
  • 아티팩트는 대화 옆 창에 열리는 결과물이고, 사이드바 '아티팩트' 탭에 모인다
  • 모든 플랜에서 만들 수 있다. 설정에서 "코드 실행 및 파일 생성" 이 켜져 있어야 한다
  • 만드는 순서는 ① 규칙 파일 붙이기 ② 뼈대 ③ 하나씩 ④ 검산
  • 규칙은 말로 옮기지 말고 파일을 붙여라. 옮기면 조건이 날아간다
  • 고칠 땐 전체를 다시 만들지 말고 어디가 어떻게 틀렸는지 숫자로 말한다. 망가지면 되돌리면 된다
  • 경계값(이상? 초과?)과 중복 불가 조건이 가장 자주 틀린다
  • 계산기는 숫자, 체크리스트는 빠진 항목, 대시보드는 비교 대상으로 검산한다
  • 새 아티팩트는 처음엔 나만 본다. 링크로 공유해도 여는 사람도 Claude 로그인이 필요하다 (Free는 새 아티팩트 링크 공유 불가)
  • AI 기능이 든 도구는 쓰는 사람의 사용량이 차감되고, 링크로는 공유할 수 없다
  • 아티팩트는 혼자 완결되는 도구. 사내 시스템 연결은 MCP나 개발의 일이다
  • 도구를 HTML 파일로 꺼내 GitHub Pages에 올리면 계정 없는 사람도 주소로 연다. 대신 인터넷 전체 공개이고 AI·저장 기능은 멈춘다
  • 배포한 페이지는 고치면 다시 올려야 바뀐다. 방문자가 고친 내용을 남기려면 서버(데이터베이스)가 필요하다
  • 팀원이 나에게 자꾸 물어보는 기준이 있다면, 그건 내가 병목이라는 뜻이고 도구로 만들 신호다

🧑‍🏫 강사용 — 수업 전 체크리스트
  • 학생 전원 GitHub 계정 보유 여부 사전 확인 (없으면 전날 가입 안내 — 이메일 인증 필요)
