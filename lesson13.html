Claude 앱에 폴더째 맡기기

성수 팝업스토어 행사가 끝났습니다. 남은 건 영수증 17장 — 택시, 도시락, 다이소, 회식비… 파일명도 형식도 제각각이죠. 지금까지처럼 파일을 하나씩 첨부하며 대화할 수도 있습니다. 그런데 "폴더째 던져주고, 끝나면 결과만 받으면 안 되나?" — 됩니다. 오늘은 Claude 데스크톱 앱에 내 컴퓨터 폴더를 연결해서 일을 통째로 맡기는 법을 배웁니다.

📍 오늘 배우는 것 — 도구 삼총사(앱 · 폴더 맡기기 · Claude Code) 고르기, 데스크톱 앱 설치와 폴더 연결, 맡기는 일의 흐름(계획 → 실행 → 보고), 과제 정의 3요소, 결과 검수 3층위, 원본을 바꾸는 작업의 안전 수칙

왜 Cowork 메뉴가 따로 없나요? 2026년 9월 16일부터 채팅과 Cowork를 하나의 대화창으로 합치는 중입니다. 새 화면이 적용된 계정은 채팅·Cowork를 고르는 메뉴 없이, 대화창에 "이 폴더 정리해서 표로 만들어줘"처럼 결과물을 말하면 Claude가 짧게 답할지 길게 맡아 처리할지 스스로 정합니다. 적용 범위는 요금제마다 다릅니다 — Pro·Max·Ultra는 순서대로 적용 중, Team(베타)·Enterprise는 관리자가 켜야 적용되고, 무료 요금제는 Cowork를 쓸 수 없습니다. 아직 바뀌지 않은 계정은 앱에 Cowork가 따로 보일 수 있는데, 하는 일은 같습니다.

꼭 알아둘 것 — 일은 클라우드에서, 폴더는 앱을 통해서

2026년 10월 6일부터 Pro·Max 요금제에서 새로 맡긴 작업은 모두 Anthropic 서버(클라우드)에서 돕니다. 내 컴퓨터에서만 돌리게 바꾸는 설정은 없습니다. 그래서 노트북을 닫아도 작업 자체는 이어집니다. 하지만 내 컴퓨터의 폴더는 데스크톱 앱이 열려 있고 연결돼 있을 때만 읽을 수 있고, 작업에 필요한 파일이 있으면 그 파일의 사본만 클라우드로 가져가 씁니다.

⚠️ 앱을 끄면 폴더를 못 읽습니다

데스크톱 앱이 꺼지면 클라우드 작업은 계속 돌아도 내 컴퓨터에는 닿지 못합니다. 폴더를 맡긴 동안에는 앱을 켜 두세요. 반대로, 폴더 접근을 바로 끊고 싶다면 앱을 닫는 것이 가장 빠른 방법입니다.

시작하기 — 3단계

  1. 데스크톱 앱 설치 — claude.ai/download에서 내려받아 설치 → 1과정에서 쓰던 계정으로 로그인. (Windows·macOS 지원, Linux는 베타)
  2. 폴더 연결 — 대화창 입력칸 옆 + 메뉴 → 폴더 추가로 맡길 폴더를 고릅니다. 한 번 허락한 폴더는 앱 설정의 신뢰한 폴더 목록에 남습니다.
  3. 결과물을 말하며 맡기기 — "이 폴더를 보고 ○○ 파일을 만들어줘"처럼 무엇을 만들지를 말합니다. 질문형("이거 어떻게 정리해?")으로 물으면 대화로 답만 하는 경우가 많습니다.

💡 화면 구성은 업데이트마다 계속 바뀝니다. 버튼을 못 찾겠으면 앱 안에서 Claude에게 직접 "내 컴퓨터 폴더를 연결해서 작업하려면 어디서 시작해?"라고 물어보세요. 화면이 또 바뀌어도 이 방법은 계속 통합니다.

🔐 폴더 권한은 내가 정합니다. Claude는 아무 폴더나 뒤지는 게 아니라 내가 연결한 폴더에서만 움직입니다. 그래서 "실습용 복사본 폴더만 연결"이 실제로 강력한 안전장치가 됩니다.

  1. zip을 바탕화면에 새 폴더(예: 주간보고연습)로 풉니다.
  2. 데스크톱 앱을 열고 새 대화 → 입력칸 옆 + → 폴더 추가로 주간보고연습을 연결합니다.

② 메모 취합 — '맡기는' 말투로

"연결한 폴더의 이번 주 메모들(회의록·메신저 캡처·메일)을 보고 항목별로 정리해서 메모정리.md 파일로 저장해줘. 각 항목은 '결정됨 / 미정'으로 구분하고, 어느 파일에서 나온 내용인지 출처를 붙여줘. 내용이 서로 다르면 하나를 고르지 말고 둘 다 적어줘. 이 폴더 안에서만 작업해."

✅ 확인할 것 — 파일이 내 폴더에 생겼나?

탐색기로 주간보고연습 폴더를 열어 메모정리.md가 실제로 생겼는지 보세요. 대화창이 아니라 내 폴더에 결과가 생긴 것 — 이게 첨부와 폴더 연결의 차이입니다.

③ 초안 작성 — 실적 칸은 비워 두기

"메모 정리를 바탕으로 팀장님께 올릴 주간보고 초안을 주간보고_초안.md로 저장해줘. 첫 줄에 이번 주 핵심 한 문장, 그다음 '실적 / 진행 중 / 결정 필요' 순서로. '실적' 칸은 내용을 쓰지 말고 [실적 집계 예정]이라고만 남겨. '미정' 항목은 '결정 필요'에만 넣어."

💡 오늘은 [실적 집계 예정] 칸을 비워 둔 채로 끝냅니다. 실적 숫자는 매주 같은 계산이라 실습 A 기준으로 Claude Code 몫이고, Claude Code는 다음 차시에 배웁니다. 오늘은 Cowork가 맡을 메모 취합·초안까지만 합니다.

④ 사람 확인

메모정리.md의 항목 2개를 골라 출처로 적힌 원본 파일을 직접 열어 맞는지 봅니다.

✅ 확인할 것 — '미정'이 '결정'으로 바뀌지 않았나?

메모 정리에서 '미정'이던 항목이 초안에서 결정된 것처럼 쓰였다면, 그게 사람 확인 단계가 잡아낸 실수입니다. 출처가 원본과 다른 항목도 표시해 두세요.

📌 2절 한 줄 요약

앱을 깔고 폴더를 연결하면 결과물이 내 폴더에 바로 생긴다. 대신 앱을 켜 둬야 하고, 파일을 바꿀 수 있게 된 만큼 조심해야 한다.

원본을 바꾸는 작업 — 되돌리기 어렵다

맡기는 일은 세 종류가 있습니다. 앞의 둘은 새 파일을 만들지만, 세 번째는 원본 자체를 바꿉니다.

유형하는 일예결과물
① 분류·집계형뒤섞인 파일을 규칙대로 나누고 합산영수증 → 경비 보고서 (실습 C)새 파일
② 조립형여러 조각 자료를 모아 한 문서로메모 → 주간보고 (실습 B)새 파일
③ 정리·변환형기존 파일 자체를 규칙에 맞게 바꿈파일명 정리 (실습 E)원본이 바뀜 ⚠️
🚨 실제로 일어나는 사고

한 팀원이 복사본을 건너뛰고 원본 계약서 폴더를 그대로 맡겼습니다. "파일명을 정리해줘"라는 과제문이 원본 파일명을 전부 바꿔 버렸고, 어떤 파일이 어떤 계약서였는지 팀 전체가 한참을 헤맸습니다.

③에는 두 가지가 꼭 필요합니다.

  • 백업 복사본 — 맡기기 전에 폴더를 한 번 더 복사해 둔다.
  • "모르면 건드리지 마" — 판단할 근거가 없는 파일은 이름을 바꾸지 말고 목록으로만 알려 달라고 한다. 지우는 건 절대 맡기지 않는다.

💡 조립형(②)은 또 다른 함정이 있습니다. 분류형은 틀리면 눈에 보이지만, 조립형은 그럴듯한 문서 한 장이라 틀린 게 안 보입니다. 그래서 조립형 과제문엔 "어느 자료를 썼는지 출처를 남겨줘"를 꼭 넣으세요. 실습 B에서 출처를 붙이게 한 이유입니다.

🛠 실습 E — [회의자료 관리 · 파일명 정리 단계 → Cowork] 엉망인 회의자료 파일명 정리

순서는 ① 백업 만들고 연결 → ② 안전장치 넣어 맡기기 → ③ 결과 검수.
새 대화에서 시작합니다.

📎 준비물
  • 회의자료 폴더(messy_meeting_files.zip) · zip · 15개 파일 (날짜 형식 제각각, 날짜 없는 파일 3개, 중복 1쌍)

① 백업 만들고 연결

  1. zip을 회의자료정리연습 폴더에 풀고, 그 폴더를 한 번 더 복사해 회의자료정리연습_백업을 만듭니다.
  2. 새 대화에서 회의자료정리연습만 연결합니다. 백업 폴더는 연결하지 않습니다.

② 안전장치 넣어 맡기기

"이 폴더의 파일명을 안내_읽어주세요.txt의 규칙대로 정리해줘. 이름에서 날짜를 알 수 없으면 파일 내용을 열어 날짜를 찾아보고, 내용에도 날짜가 없으면 이름을 바꾸지 말고 이름변경_보류.txt에 파일명과 이유를 적어줘. 내용이 거의 같은 중복 파일이 있으면 알려주기만 하고, 지우지는 마. 이 폴더 안에서만 작업해. 바꾸기 전에 '바꿀 이름 목록'을 먼저 보여주고 내 확인을 받아."

💡 마지막 문장이 핵심입니다. 원본을 바꾸는 작업은 바꾸기 전 목록을 먼저 받아 보고 허락하세요. 계획 단계에서 멈추는 습관의 실전판입니다.

③ 결과 검수

✅ 확인할 것 — '모르면 건드리지 마'가 지켜졌나?
  • 날짜 없는 3개(asdf.txt, 복사본 (2).txt, 기타자료_정리안됨.txt)가 이름 그대로 남고 보류 목록에 올라갔나?
  • 내용에만 날짜가 있던 회의록.txt(7/5), 무제-1.txt(7/12)는 제대로 바뀌었나?
  • 제각각이던 날짜 형식이 전부 YYYYMMDD로 통일됐나?
  • 중복 2개를 알려주기만 하고 지우지 않았나?

📝 더 해보고 싶다면 — 백업 폴더를 또 복사해서 안전장치를 다 빼고 "이 폴더 파일명을 날짜_회의종류_버전 형식으로 정리해줘"만 시켜 보세요. 날짜를 모르는 파일에 이름을 지어내는지 비교하면, 안전장치 한 줄의 값어치가 몸에 남습니다.

📌 5절 한 줄 요약

원본을 바꾸는 작업은 백업 → 바꿀 목록 먼저 확인 → 모르면 건드리지 않기 → 지우기 금지.

자주 묻는 질문

Q. 웹(claude.ai)에서도 폴더를 맡길 수 있나요?
A. 웹과 모바일에서도 맡기는 방식으로 일할 수 있지만, 내 컴퓨터의 폴더는 데스크톱 앱을 통해서만 연결됩니다. 웹에서는 파일을 첨부하는 방식으로 하세요.

Q. 맡겨 놓고 다른 일 해도 되나요?
A. 계획만 확인하고 나면 됩니다. 다만 질문이 오면 답해야 진행되니 가끔 확인하세요. 그리고 폴더 작업 중에는 데스크톱 앱을 끄지 마세요.

Q. 회사 자료를 맡겨도 되나요?
A. 회사 정책이 먼저입니다. 사내 규정을 확인하고, 필요하면 IT·보안팀에 문의하세요. 실제 업무에 쓸 때는 민감 자료가 없는 작업용 폴더만 연결하는 게 좋습니다. 작업에 쓰이는 파일은 사본이 클라우드로 전달된다는 점도 기억하세요.

Q. 파일이 수백 개면요?
A. 시간이 더 걸립니다. 처음엔 오늘처럼 10~20개로 감을 잡고, 너무 크면 하위 폴더 단위로 나눠 맡기세요.

Q. Claude Code도 폴더를 다룬다던데, 뭐가 달라요?
A. 앱에 맡기면 결과물이 남고, Claude Code는 그 일을 하는 프로그램(도구)까지 남깁니다. 다음 차시에서 자세히 비교합니다.

내 업무라면?

  1. 실습 A 프롬프트의 첫 두 줄에 내 업무 이름과 설명을 넣어 다시 돌려 보고, Cowork로 나온 단계 하나를 고릅니다. 마땅한 업무가 없으면 내 컴퓨터에서 "정리해야 하는데 미루고 있는 폴더" 하나를 떠올립니다. (영수증? 시안? 회의 자료? 다운로드 폴더?)
  2. 그게 분류형·조립형·정리형 중 무엇인지 판별합니다.
  3. 마스터 프롬프트로 과제문 한 문단을 씁니다. 결과물 이름까지 정하는 게 핵심입니다.
  4. 폴더 5분 정리를 하고, 복사본을 연결해 맡겨 봅니다.

💡 마음에 드는 과제문은 메모장에 저장해 두세요. 같은 일이 또 오면 그대로 다시 쓰면 됩니다. 규칙 부분은 아예 폴더의 안내_읽어주세요.txt로 넣어 두면 과제문이 한두 줄로 줄어듭니다.

오늘 정리

📌 세 개만 기억하기
  1. 앱 · 폴더 맡기기 · Code는 분업 — 갈림길은 반복되는 게 무엇이냐.
  2. 과제 정의가 90% — 결과물 · 규칙 · 애매하면 표시. 그리고 계획 단계에서 멈출 줄 안다.
  3. 맡긴 만큼 검수한다 — 원본을 바꾸는 일은 백업부터.

전체 정리

  • 프로그램은 Claude 데스크톱 앱 하나. 대화창(대화 · 폴더 연결하면 Cowork)과 Code 탭(Claude Code), 들어가는 곳은 두 군데, 일하는 방식은 셋.
  • 데스크톱 앱에 폴더를 연결하면 결과물이 내 폴더에 바로 생긴다. 작업은 클라우드에서 돌아도 폴더는 앱이 켜져 있어야 읽힌다.
  • 흐름은 계획 → 실행 → 보고. 과제문 끝에 "계획 먼저 보여줘"를 붙인다.
  • Claude가 되물으면 '이번 건'이 아니라 '규칙'으로 답한다.
  • 맡기기 전 폴더 5분 정리 — 관련 없는 파일 빼기, 구버전 정리, 규칙은 안내 파일로.
  • 조립형엔 출처 남기기, 검수엔 검수표, 정리형엔 백업과 바꿀 목록 확인.
